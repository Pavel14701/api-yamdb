## Issues — ОБЯЗАТЕЛЬНЫЕ (25)

### Павел

**P1. [05] permissions.py:21 — литералы ролей → константы**
Вместо литералов ролей использовать константу значения роли; те же константы — в choices поля модели. Минимум: константы в модуле; максимум: отдельный модуль констант ролей.

**P2. [29] api/views.py:77 — убрать переопределение пагинации**
Зачем переопределена пагинация? Если глобально задан PAGE_SIZE, LimitOffset всегда включён (limit по умолчанию = page size). Убрать глобальную настройку PAGE_SIZE в settings, если пагинация не нужна по умолчанию.

**P3. [77] users/models.py:7 — валидатор username: запрет `me` + regex Django**
Запретить `me` и не потерять встроенную регулярку Django (см. django/contrib/auth/models.py#L330). Либо два валидатора (встроенный + самодельный про `me`), либо один объединяющий. Валидаторы подхватятся model serializer'ом.

**P4. [79] users/models.py:29 — max_length → файл констант**
Все максимальные длины строк в моделях (особенно повторяющиеся!) — в файл констант (НЕ settings.py).

**P5. [80] users/models.py:54 — убрать ordering по id**
Какой смысл упорядочивать по ИД, особенно если он случайный (UUID)?

**P6. [83] users/utils.py:1 — переименовать модуль**
`utils` — антипаттерн (риск сваливания всего подряд, циклические импорты). Дать конкретное имя: `auth`, `codes` и т.п. Обновить импорты (api/views.py: `generate_confirmation_code, hash_confirmation_code`).
